# シュガー・ステージ 〜夢見るお菓子劇場〜

赤いビロードの幕が上がる「お菓子の劇場」を舞台にした、React製のマッチ3パズルゲームです。
ポスターの配色（深紅の幕・キャンディピンク・ティール×クリームの光線・金の装飾）と、
ロリポップや板チョコ、綿あめなどのお菓子の形をゲームの世界に取り入れています（キャラクターとお菓子のデザインはすべてオリジナル）。

## 遊び方
- となりのお菓子を **ドラッグ** または **2回クリック** で入れ替え、縦横3つ以上そろえて消す
- 4つ → ストライプ（1列消し）／ L・T字 → ラッピング（3×3爆発）／ 5つ → レインボードロップ（同じ種類を全消し）
- スペシャル同士を入れ替えると十字消し・巨大爆発などの合体技
- 手数内に目標（スコア／お菓子集め／チョコの床溶かし）を達成するとクリア。余った手数は「カーテンコール」でボーナスに
- 全5幕・★評価・8つの実績。進行状況はブラウザに保存されます
- キーボード：`H` でヒント、`Esc` で選択解除

## 起動
```bash
npm install
npm run dev          # 開発サーバー
npm run build        # dist/ に本番ビルド
npm run build:single # dist-single/index.html に1ファイル版を出力
```

## 構成
```
src/
  engine.js            盤面ロジック（マッチ判定・特殊効果の連鎖・落下・シャッフル）
  levels.js            ステージ定義・お菓子・実績
  audio.js             Web Audioで合成する効果音とオルゴール風BGM（音源ファイル不要）
  App.jsx              画面遷移（幕の開閉）・タイトル・演目選択・セーブ・実績
  components/
    GameScreen.jsx     ゲーム本体（連鎖アニメーション、演出、HUD、リザルト）
    Candy.jsx          お菓子のSVGアート
    Mascot.jsx         案内役「ボンボ」
    Scenery.jsx        背景・幕・花などの舞台装置
  styles.css           1600×900 の舞台を画面サイズに合わせて拡大縮小
```
